BorisRay 0.2.0 — бесплатный клиент, Windows 11, Intel/AMD x64

Программа бесплатна; VPN-подписку и серверы предоставляет выбранный тобой провайдер.

1. Запусти BorisRay-Windows-Setup-x64-0.2.0.exe. Установщик разместит приложение в Program Files и добавит ярлык в «Пуск». Для переносной версии полностью распакуй ZIP; сохрани все файлы и папку core рядом с BorisRay.exe.
2. Запусти BorisRay.exe и разреши системное окно Windows. Для системного туннеля нужны права администратора.
3. На экране «Подключение» добавь свою HTTPS-подписку от VPN-провайдера, ссылку профиля или текстовый файл. Поддерживаются списки ссылок и Base64, Xray/sing-box JSON и Clash YAML. Протоколы: VLESS (TLS/Reality/без TLS), VMess, Trojan, Shadowsocks AEAD/2022, Hysteria2, TUIC и SOCKS5. Для VLESS/VMess/Trojan: TCP, WebSocket, gRPC, HTTP/HTTPUpgrade. Зашифрованные happ://crypto, XHTTP, цепочки и внешние плагины пока не поддерживаются. Ошибка импорта сохраняет прежнюю подписку; неподдерживаемый профиль не пропускается молча.
4. Отключи другой VPN, выбери сервер или автовыбор канала и нажми «Подключить VPN».
5. В «Приложениях» добавляй настоящие .exe или ярлыки; ярлык разрешается до пути программы. Папки и подпапки включаются отдельно.
6. В «Сайтах» добавляй домены без https:// и пути. Правило действует также на поддомены. Более точный домен имеет приоритет, затем применяются правила приложений и общий маршрут.
7. После изменения правил нажми «Применить маршруты». Для остановки — «Отключить VPN». Закрытие приложения останавливает принадлежащий ему движок.

Страны определяются по явным названиям профилей; неизвестная страна не угадывается по адресу. Доступны только серверы из твоей подписки.
«Соединения» показывает адрес, процесс, цепочку, правило и байты из движка. Короткие подключения между опросами могут отсутствовать.
Замер: 5 МиБ загрузки, 1 МиБ отдачи, три HTTPS-запроса через выбранный VPN. Это HTTPS-задержка, а не ICMP-пинг.

Персональная сборка без подписи издателя Windows. Windows может показать предупреждение неизвестного издателя. Проверяй SHA256 по ссылке загрузки.
Подписка отсутствует в архиве. На этом компьютере она зашифрована DPAPI и привязана к учётной записи Windows. Готовых подписок и серверных ключей в приложении нет.
Проверка сборки: CI проверяет сборку, конфигурации ядра и родной интерфейс. Реальное подключение, DNS и правила должны пройти проверку на целевом Windows 11.

Обновления: «О приложении» → «Проверить обновления». Скачай новый установщик BorisRay, отключи VPN, закрой старую версию и установи новую. В установщике тот же AppId; обновление идёт поверх прежней установки. Локальная подписка сохраняется в профиле пользователя.
Удаление: Параметры Windows → Приложения → Установленные приложения → BorisRay. Подписка и правила в %LOCALAPPDATA%\BorisRay сохраняются при удалении; удалить их можно отдельно.
