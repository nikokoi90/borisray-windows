BorisRay 0.1.0 — бесплатный клиент, Windows 11, Intel/AMD x64

Программа бесплатна; VPN-подписку и серверы предоставляет выбранный тобой провайдер.

1. Полностью распакуй ZIP в отдельную папку. Сохрани все файлы и папку core рядом с BorisRay.exe.
2. Запусти BorisRay.exe и разреши системное окно Windows. Для системного туннеля нужны права администратора.
3. На экране «Подключение» добавь свою HTTPS-подписку от VPN-провайдера, ссылку профиля или текстовый файл. Поддерживаются VLESS Reality/TCP и Hysteria2/UDP; JSON, Clash YAML и другие протоколы пока не поддерживаются.
4. Отключи другой VPN, выбери канал (обычно UDP) и нажми «Подключить VPN».
5. В «Приложениях» добавляй настоящие .exe или ярлыки; ярлык разрешается до пути программы. Папки и подпапки включаются отдельно.
6. В «Сайтах» добавляй домены без https:// и пути. Правило действует также на поддомены. Более точный домен имеет приоритет, затем применяются правила приложений и общий маршрут.
7. После изменения правил нажми «Применить маршруты». Для остановки — «Отключить VPN». Закрытие приложения останавливает принадлежащий ему движок.

Страны определяются по явным названиям профилей; неизвестная страна не угадывается по адресу. Доступны только серверы из твоей подписки.
«Соединения» показывает адрес, процесс, цепочку, правило и байты из движка. Короткие подключения между опросами могут отсутствовать.
Замер: 5 МиБ загрузки, 1 МиБ отдачи, три HTTPS-запроса через выбранный VPN. Это HTTPS-задержка, а не ICMP-пинг.

Персональная сборка без подписи издателя Windows. Windows может показать предупреждение неизвестного издателя. Проверяй SHA256 по ссылке загрузки.
Подписка отсутствует в архиве. На этом компьютере она зашифрована DPAPI и привязана к учётной записи Windows. Готовых подписок и серверных ключей в приложении нет.
Первая версия: CI проверяет сборку, конфигурации ядра и родной интерфейс. Реальное подключение, DNS и правила должны пройти проверку на целевом Windows 11.

Обновления: «О приложении» → «Проверить обновления». Скачай новый ZIP BorisRay, отключи VPN, закрой старую версию и распакуй новую. Локальная подписка сохраняется в профиле пользователя.
